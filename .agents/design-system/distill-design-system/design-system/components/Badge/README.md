# Badge

A small `fill-strong` label with `radius-sm` corners.

- Default: the header kicker naming the current mode, `caption-strong` in `ink`.
- `variant="provenance"`: the `badge` style (10px, uppercase, wide tracking) in `ink-muted`. Every results section title carries one: `measured`, `inferred` or `ai`. Never omit it — provenance is the product's promise.

Consumer supplies: the text; lowercase source words are uppercased by the style.
