# CodeBlock

The Markdown output pane: a scrollable `pre` on `surface-sunken`.

- `code-block` type (mono 12px, 1.625 leading), `space-4` padding, `line` border, `radius-lg`, horizontal scroll rather than wrapping.
- Show the exact text that the download button will save.

Consumer supplies: the text (children).

Hand-written from `app/page.tsx`.
